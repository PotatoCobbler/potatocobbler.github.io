# van der Ham NMR static site

This folder is a standalone GitHub Pages version of the supplied van der Ham NMR site.

## Deploy
Copy the contents of this folder into the root of the `potatocobbler.github.io` repository.

Keep the repository's custom domain as `vanderhamnmr.com`.

NMRpaint remains a separate project site under `/NMRPaint/` until its deployment is deliberately migrated.
