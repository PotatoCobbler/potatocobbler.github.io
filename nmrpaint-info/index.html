Explore NMRpaint

Welcome to NMRpaint! This tool aims provides an interactive environment for the development of NMR pulse programs. It has been designed for both graphic-to-text and text-to-graphic conversion. This tool is especially useful for novice NMR spectroscopists, students or those who need to develop custom pulse programs on only an occasional basis.
