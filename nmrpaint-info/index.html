About NMRpaint

Welcome to NMRpaint! This tool aims to provide an interactive environment for the development of NMR pulse programs. It has been designed for both graphic-to-text and text-to-graphic conversion. This makes NMRpaint particularly useful for novice NMR spectroscopists, students or those who need to develop custom pulse programs on only an occasional basis.
Simply click and place elements on the canvas, hit the "update element" button and a ready-to-execute, Bruker TopSpin compatible pulse program is generated. Simply hit the orange download button and the extension-less pulse program file gets downloaded.

Source code and development

NMRpaint is primarily developed in Python using Jupyter, `ipywidgets`, and `ipycanvas`, with embedded HTML/CSS for the user interface. The application uses JSON-based metadata to preserve pulse-program information between its graphical and textual representations. The source code is in active development. Feel free to reach out if you have any suggestions or find any bugs.
